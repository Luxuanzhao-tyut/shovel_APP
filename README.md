# 露天矿电铲样机控制台

面向露天矿电铲缩比样机的 **Python 上位机控制、PLC
通信、状态监测、数据记录与挖掘轨迹执行平台**。

当前稳定版本：**V2.3.5.1**

> 本版本已完成样机实机联调，当前作为后续轨迹规划与自主挖掘开发的稳定基线。软件直接涉及真实设备运动，首次连接或修改控制参数后，应在空载、低速、现场可急停条件下验证。

## 1. 当前版本主要能力

V2.3.5.1 已实现 PLC
通信与实时状态读取、上位机远程控制、提升/推压/回转点动控制、整车行走、数据记录、历史速度序列复现、挖掘轨迹编辑与导入，以及提升---推压---回转三机构联合轨迹执行。

联合轨迹执行支持从设备当前状态自动接入
P1，并连续通过中间轨迹点，仅在最终目标执行终端停止控制。中间 P
点主要用于描述轨迹形状，而不是要求机构逐点精确停车。

## 2. 系统控制链

``` text
轨迹规划 / 人工输入
        ↓
Python 上位机
        ↓
位置外环 / 速度指令生成
        ↓
DB401 控制命令
        ↓
Siemens PLC / 驱动器
        ↓
电机与机械机构
        ↓
编码器 / 状态反馈
        ↓
DB400
        ↓
Python 上位机
```

当前控制架构可概括为：**PC 侧位置外环 +
PLC/驱动侧速度执行内环**。上位机根据目标位置与实时反馈误差生成带方向的速度命令，持续读取反馈并更新控制量。

## 3. PLC 通信

默认 PLC 参数：

``` text
IP   : 192.168.2.20
Rack : 0
Slot : 1
```

当前约定：`DB400` 用于 PLC → 上位机的状态反馈，`DB401` 用于上位机 → PLC
的控制命令。具体 PLC 参数和变量映射以
`config/plc_config.yaml`、`config/variable_map.yaml` 及实际 PLC
工程为准。

## 4. 点动、监测与记录

点动控制的基本过程为：

``` text
按下运动按钮 → 检查安全条件 → 写入速度/方向 → 机构运动
                                      ↓
松开按钮 ← 清方向并写零速 ←───────────┘
```

点动主要用于 PLC 通信、电机方向、编码器方向和低速联调。程序持续读取 PLC
反馈，并对状态新鲜度进行检查；状态过期或未知时，不允许启动依赖实时反馈的运动。

连接 PLC 后可持续记录运行数据，典型输出为：

``` text
records/自动记录_YYYYMMDD_HHMMSS.csv
```

这些数据可用于人工操作采集、控制效果分析、编码器分析、轨迹跟踪分析及后续学习算法的数据准备。

## 5. 两类轨迹/复现功能

### 历史速度复现

历史 CSV 复现属于早期示教回放功能，本质是重放历史运动方向与速度序列。

### 挖掘位置轨迹

当前挖掘轨迹使用：

``` text
P_i = (提升编码器, 推压编码器, 回转角度)
```

导入正式轨迹 `P1...PN` 后，程序读取 PLC 当前状态并自动形成：

``` text
P_current → P1 → P2 → ... → PN
```

`P_current → P1` 是自动接入段，`P1 → ... → PN`
是正式规划轨迹。用户不需要把当前状态人工写入轨迹文件。

V2.3.5.1
采用连续通过方式执行中间点。中间点承担轨迹离散和路径形状描述作用，最终点才承担明确的终止目标作用。

## 6. 位置外环

联合轨迹执行的基本控制关系为：

``` text
e = q_ref - q
v_cmd = sat(Kp × e, -v_max, +v_max)
```

其中 `q_ref` 为当前参考位置，`q` 为 PLC 实时反馈，`Kp`
为位置外环比例系数，`v_max` 为自动轨迹速度上限。

因此当前自动轨迹不是固定速度序列重放，而是：

``` text
实时位置反馈
      ↓
计算位置误差
      ↓
生成下一周期速度
      ↓
写入 PLC
      ↓
读取新的反馈并继续修正
```

## 7. 速度参数

现场可调速度参数集中在：

``` text
config/operator_settings.yaml
```

包括
`default_percent`、`max_percent`、`step_percent`、`auto_min_percent`
等。修改后需重新启动控制台。

真实样机应按低速 → 中速 →
正常工作速度逐级验证，不建议为了提高速度直接大幅放宽自动轨迹速度限制。

## 8. 安全机制

当前程序包含 PLC
在线/状态新鲜度、远程控制条件、作业模式、故障、整流、松闸反馈、机构限位和停止清输出等检查。

**实体硬急停仍是现场最高等级保护。**

新功能实机测试建议遵循：

``` text
空载 → 单机构 → 小位移 → 低速度 → 三机构联合 → 短轨迹 → 完整轨迹
```

## 9. 启动与构建

首次构建可双击：

``` text
BUILD_EXE.bat
```

构建后的程序位于：

``` text
dist/露天矿电铲样机控制台/露天矿电铲样机控制台.exe
```

已有构建时可双击 `START_UI.bat`。项目同时保留 `app.py`、`start_app.py`
等 Python 入口，依赖见 `requirements.txt` 和 `requirements-ui.txt`。

## 11. V2.3.5.1 工程状态

V2.3.5.1 作为当前实机验证后的稳定基线冻结。当前已经形成：

``` text
PLC 通信
   ↓
手动控制
   ↓
实时反馈
   ↓
数据记录
   ↓
三机构位置闭环
   ↓
多点联合轨迹
   ↓
连续轨迹执行
```

当前版本重点不是追求每个离散中间点的零误差，而是使机构沿给定联合轨迹连续执行，并在最终目标附近可靠停止。

## 12. 当前能力边界与下一阶段

当前版本解决的是"给定提升---推压---回转轨迹后，样机如何执行"。它还不是完整的自主挖掘规划系统。

下一阶段的主链路应为：

``` text
料堆点云 / 可挖区域
        ↓
选择挖掘目标
        ↓
规划铲齿三维轨迹
        ↓
电铲正/逆运动学
        ↓
提升—推压—回转联合轨迹
        ↓
V2.3.5.1 控制执行层
        ↓
PLC / 样机
```

因此 V2.3.5.1 更适合作为后续自主轨迹规划算法的
**稳定执行后端**。后续重点包括样机几何模型与铲齿运动学、三维铲齿轨迹到机构轨迹转换、点云可挖区域接入、轨迹平滑与拐点过渡、负载/电流/力矩反馈，以及卡滞等异常保护。

## 13. 版本管理

建议分支保持：

``` text
main
release/v1
release/v2.3.5.1
dev
```

`release/v1` 保存初始历史基线；`release/v2.3.5.1`
保存当前实机验证稳定版本；`dev`
用于后续运动学、轨迹规划和自主挖掘开发；`main`
保存经过验证的最新稳定版本。

## 14. 重要说明

本仓库用于科研样机开发和实验验证。涉及 PLC 地址、DB400/DB401
映射、速度限幅、运动方向、编码器目标、松闸、急停、限位和自动轨迹控制的任何修改，都应在实机低速条件下重新验证。

不要仅凭仿真、单元测试或软件界面显示判断真实设备安全状态。

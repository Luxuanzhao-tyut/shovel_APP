# 露天矿电铲样机控制台

## 1. 运行

第一次使用，双击 `BUILD_EXE.bat`。

构建成功后，程序位于：

`dist\露天矿电铲样机控制台\露天矿电铲样机控制台.exe`

也可以双击 `START_UI.bat` 启动已经构建好的程序。

默认 PLC：`192.168.2.20`，Rack=`0`，Slot=`1`。DB400 用于反馈，DB401 用于上位机控制命令。

## 2. 主界面

- 顶部：PLC 连接、急停、故障复位、整流启停、模式、三机构松闸/抱闸。
- 左侧：提升、推压、回转手动控制与关键反馈。
- 中间：开斗、喇叭、自动到目标、数据导出/导入与复现。
- 右侧：整车前进/后退/左右转、左右履带独立控制，以及实时/历史数据。

## 3. 自动到目标

每个轴显示当前反馈值、目标值、`取当前`、速度上限和 `执行到目标`。

点击 `执行到目标` 后，程序会先检查 PLC 在线状态和必要联锁，然后写入目标值、速度上限并触发对应自动执行命令。

- 提升目标：暂按 PLC 工程量使用，反馈来自 `DB400.DBD142`。
- 推压目标：暂按 PLC 工程量使用，反馈来自 `DB400.DBD146`。
- 回转目标：按角度目标使用，反馈来自 `DB400.DBD150`；零点、正方向和环绕方式仍建议现场确认。

首次验证自动位置功能时，建议使用空载、单轴、小目标变化和较低速度上限，并持续观察反馈数据。

## 4. 停止与制动

- 手动提升、推压、回转和行走：按住运行，松开后清方向并写零速。
- 急停：清除运动输出并发送 PLC 急停请求。
- 抱闸：机构制动，不等同于普通停止。
- 整流停止：动力链控制，不等同于普通停止或抱闸。

实体硬急停仍是现场最高等级保护。

## 5. 数据记录与历史回看

连接 PLC 后自动创建记录文件：

`records\自动记录_YYYYMMDD_HHMMSS.csv`

程序约每 100 ms 保存已映射的 DB400 反馈。界面可通过时间滑块查看近期历史；完整会话持续写入 CSV。

## 6. 数据导入与复现

`导入历史 CSV` 用于历史动作数据分析与速度序列复现。

速度复现和自动到目标是两条不同控制路径：

- 速度复现：按历史记录重放方向与速度；
- 自动到目标：下发目标位置和速度上限，由 PLC 的位置控制路径执行。


## 现场可调速度参数

不需要修改 Python 代码。速度相关设置集中在：

`config/operator_settings.yaml`

- `default_percent`：界面启动时默认速度
- `max_percent`：界面最大可输入速度，同时也是后台真实写入限幅
- `step_percent`：速度输入步长
- `auto_min_percent`：自动到目标的最小速度上限

修改保存后，关闭并重新启动控制台即可生效。

构建成 EXE 后，请修改：
`dist/露天矿电铲样机控制台/config/operator_settings.yaml`

`max_percent` 最大允许设置为 100。

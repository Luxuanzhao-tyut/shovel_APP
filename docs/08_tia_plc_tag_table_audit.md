识别363个Tag；TagTable Properties有表头及7个分组，含Path/BelongsToUnit/Accessibility。工作簿缺常规尺寸信息，按实际行遍历，没有将未知max_row当作空表。

## 地址层级

%I=输入区，%Q=输出区，%M=Marker内部存储；%IW/%MW表示输入/Marker的16位字访问，%ID/%MD表示32位双字访问。
W/D是访问宽度，不等于变量语义：例如%IW514对应Int，而%IW518对应Word；%ID72在表中是Real，并不能因为D就解释为整数。
本次不改为直接读I区、不直接写Q/M，不把这些字节号变为DB偏移。

提升编码器 DWord %ID46（行67），推压编码器 DWord %ID62（行68）。与同名DB REAL之间的转换未知。

# 11. DB401 真实写 PLC 实现说明

## 1. 证据链

本版真实写并非根据地址猜测实现，而是组合了三类证据：

- TIA Portal：确认 DB401 控制点及 REAL 偏移，包括回转右 `3.0`、开斗 `3.1`、喇叭 `3.2`、自动开始 `3.3/3.4/3.5`、目标位置 `DBD6/10/14`、设定速度 `DBD18/22/26`。
- Java `S7WriteUtils`：确认 BOOL 读-改-写、REAL float32 写、写后立即回读；确认历史脉冲 2000 ms。
- Java `AuxServiceImpl` / `ButtonServiceImpl`：确认 100 ms 心跳、本地/远程保持型互斥，其余按钮主要为脉冲型。

## 2. 新代码结构

- `src/plc/s7_client.py`：线程安全 S7 I/O，未武装时最低写入口也拒绝。
- `src/plc/live_control.py`：真实写核心。
  - `VerifiedDB401Writer`：BOOL/REAL/连续块写与回读。
  - `LiveControlManager`：会话武装、10 Hz 心跳、联锁、点动、双履带组合、停止策略。
- `src/ui/control_facade.py`：UI 未武装时走 preview，已武装时才进入 LiveControlManager。
- `src/ui/main_window.py`：增加真实写武装区，运动按钮改为按住运行/松手清零。

## 3. 写入时序

### 单轴点动启动

```text
DB400 联锁通过
  ↓
写 DBD18/22/26 速度并回读
  ↓
同一方向对的 BOOL 一次 RMW 设置（一个 TRUE、另一个 FALSE）
```

### 单轴停止

```text
先把两个方向 BOOL 都置 FALSE
  ↓
再把该轴速度置 0
```

### 双履带启动

```text
一次写 8 字节：DBD18(右) + DBD22(左)
  ↓
一次 RMW：DBX2.3..2.6 四个方向位
```

### 双履带停止

```text
先一次清 DBX2.3..2.6
  ↓
再一次写 DBD18=0 + DBD22=0
```

这减少了旧 Java `writeUpDownLeftRightAtomic()` 名义“原子”但实际逐变量顺序写的问题，但仍不宣称等价于 PLC 侧事务/握手。

## 4. 仍需现场确认的四项

1. `DB401.DBX0.4` 心跳停止后 PLC 实际是否自动撤销远程控制/停止运动，以及超时时间。
2. 2000 ms 按钮脉冲是否确有必要，可否缩短到 200~500 ms。
3. DBD18/22/26 的工程单位和最终允许范围。
4. DB401 到 DB404 的内部处理、限幅与互锁是否还有未暴露到 DB400 的条件。

在上述 4 项未闭环前，本版本应作为“受控真机联调版”，不是最终无人化运行版本。

# 现场真写 PLC 验收清单

按顺序执行，前一项不通过不要进入下一项。

| 阶段 | 操作 | 必须看到的结果 |
|---|---|---|
| 1 | 连接 `192.168.2.20 / 0 / 1` | DB400 每 100 ms 刷新，无持续通信异常 |
| 2 | 不武装，点击任意控制 | 日志只显示“预演”，DB401 不应改变 |
| 3 | 武装 | 程序先清方向/速度，再开始 10 Hz 心跳 |
| 4 | 观察心跳 | `DB401.DBX0.4` 0/1 翻转；确认 DB400“通讯正常”的 PLC 实际语义 |
| 5 | 切换远程 | DB401 0.0/0.1 互斥，DB400 远程模式反馈变 TRUE |
| 6 | 喇叭按住/松开 | `DB401.DBX3.2` 跟随按压，确认动作与释放 |
| 7 | 挖掘/行走模式脉冲 | DB400 对应模式反馈正确，且另一模式退出 |
| 8 | 松闸/抱闸 | DB400 对应松闸指示反馈与现场机构一致 |
| 9 | 单轴低速点动 | 速度从 1~2 起；按住运动，松手方向先归零、速度随后为 0 |
| 10 | 限位试验 | 任一已知限位触发时，软件拒绝对应机构继续点动 |
| 11 | 双履带 | 左右速度/方向与 UI 一致，松手后两个履带均停止 |
| 12 | 心跳失联试验 | 在安全架空/断动力条件下验证 PLC 对心跳丢失的真实处置 |

### 必须记录

- 每一步 DB400、DB401、DB404 截图或导出；
- 命令时间、反馈时间、动作结果；
- 速度原始值与实际电机/整车速度；
- 2000 ms 脉冲的 PLC 反馈变化；
- 心跳停止后的 PLC 响应时间。

首次运动测试必须有现场监护，实体硬急停应由独立人员随时可操作。

# 默认边界

write_enabled=false，dry_run=true。无import自动连接、无自动远程、无心跳写、无松闸、无脉冲线程、无真实回放、无数据库连接。阶段二DB400和可靠DB401地址已由Excel补齐，NOT_TESTED_ON_PLC。DB401非法2.8及后续16 BOOL隔离，正式偏移仍null。
本版底层 write_bytes 不能真正写入，即使改两个开关也拒绝，因为缺少可信安全状态、地址、范围与时序。公开 API 不能直接发真实字节；不声称 Python 是抵抗用户恶意改源码的安全沙箱。

# 未知条件必拒绝

安全检查逐项覆盖写开关、dry_run、在线、远程许可、故障、必要限位、模式和批准范围。还需现场核验急停、松闸反馈、状态新鲜度、自动开始和复位时序。本版不接受随意填 true 的调用者状态作为许可。
preview是离线描述，不执行I/O，输出来源、confidence、现场状态和缺项。普通具名接口地址已知且dry_run=true时可出计划；隔离项直接抛NotImplementedError。即便write_enabled=true/dry_run=false，已知REAL仍被安全链阻止。

# 不应依赖的旧行为

Java 范围是暂定夹限，不是现场安全范围；5.0 未经证明是百分比；回转 -speed/13.2 缺标定依据。抱闸不能仅靠松闸取反推定，执行结果也不等同于严格到位。
Java 的 read-modify-write 存在相邻位竞态，“Atomic”方法不原子，mock 也会真写。Python 不运行 Java mock，不复用其自动闸动作。
停止示例只是离线计划，软件断开连接不使运行中的设备自动停机。实际急停由现场独立的硬件和 PLC 安全链负责。

# 后续真实写入的最小前提

现场负责人确认设备允许远程、周围无人、限位急停正常、工程匹配且专业人员在场；取得完整变量地址、单位、批准范围、联锁逻辑与时序。先完成可信只读状态链，再设计受控单命令写入与回读/失败处理，离线测试后由用户显式改配置。当前交付未实现这个现场执行阶段，不通过删除保护来开通。

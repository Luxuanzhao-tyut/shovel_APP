# V2.3 连续轨迹跟踪

- 中间轨迹点改为途经点，不再要求三轴全部精确停在每个中间点。
- 三轴使用公共路径进度；以最慢轴的段进度为基准，并在其前方设置小幅 look-ahead 参考。
- 上位机位置外环：`speed_cmd = sat(Kp * |q_ref-q|, min_speed, user_speed_limit)`。
- 用户填写的是“轨迹最大速度”，不是固定执行速度；控制器会在该上限内自动变速。
- 真正的电机速度内环仍由 PLC/驱动器完成，上位机不以 10 Hz 替代底层速度伺服。
- 最终点仍要求提升/推压进入编码器容差、回转进入角度容差后统一完成。
- 现场参数位于 `config/operator_settings.yaml -> trajectory_control`，第一轮真机建议最大速度 5%。
- 该版尚未加入负载/电流补偿，也未使用三次样条；先验证连续性、方向和最终停车。

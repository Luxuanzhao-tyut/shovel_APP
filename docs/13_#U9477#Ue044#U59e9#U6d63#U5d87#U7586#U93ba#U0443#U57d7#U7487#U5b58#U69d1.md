# 自动位置控制说明

## 1. UI 改动

原来的三项“自动开始”按钮和三项独立“写入目标”按钮已合并成每轴一行：

`当前值 → 目标值 → 取当前 → 速度上限 → 执行到目标`

这样避免先写数值、再到上方寻找自动按钮的两步操作。

## 2. PLC 写入顺序

| 轴 | 目标地址 | 速度上限地址 | 自动开始 |
|---|---|---|---|
| 提升 | DB401.DBD6 | DB401.DBD18 | DB401.DBX3.3 |
| 推压 | DB401.DBD10 | DB401.DBD22 | DB401.DBX3.4 |
| 回转 | DB401.DBD14 | DB401.DBD26 | DB401.DBX3.5 |

执行前仍核验 DB400 新鲜度、远程/通讯/故障、挖掘模式、整流、对应松闸和限位。

## 3. 当前值

- 提升：DB400.DBD142 (`lift_encoder`)
- 推压：DB400.DBD146 (`push_encoder`)
- 回转：DB400.DBD150 (`swing_angle`)

同时显示 DB400 的三个执行结果位，但当前只按“原始结果位 ON/OFF”展示，不擅自解释为“正在运行”或“已成功到位”。

## 4. 单位边界

当前程序故意不把提升/推压目标强行标成 cm 或 °：

- 提升目标与 DB400 提升位置反馈同域，先称为 PLC 工程量；
- 推压目标与 DB400 推压位置反馈同域，先称为 PLC 工程量；
- 回转目标按角度使用，但零点、正方向和环绕仍需现场核验。

轨迹规划文档中的 `theta`（斗杆倾角）与 PLC 提升目标之间仍需建立标定关系；推压 cm/count 与 PLC 当前工程位置之间也建议通过现场数据确认。

## 5. 推荐首次测试

1. 本地人工操作并记录 DB400，确认三个当前位置反馈随机构动作正常变化；
2. 切远程/挖掘模式并松开对应抱闸；
3. 点击“取当前”；
4. 只改变一个很小目标量；
5. 速度上限先用 1~2；
6. 点击“执行到目标”；
7. 同时观察当前位置、实际速度、执行结果位以及历史数据；
8. 任何异常立即使用顶部急停/抱闸/整流停止，并保留自动记录 CSV。
